# Chisel Project: chisel

This project uses Chisel for its documentation and issue tracking.

## Structure
- Docs: `.chisel/docs/` (Markdown)
- Issues: `.chisel/issues/` (Markdown with YAML frontmatter)

## Guidelines
When performing tasks in this repo, you can use `chisel docs` and `chisel issues` with the `--machine` flag to inspect and update the project state efficiently.
