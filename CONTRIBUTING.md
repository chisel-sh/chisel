# Contributing to Chisel

Thank you for your interest in contributing to Chisel! We aim to keep our process simple and developer-friendly.

## How to Contribute

1.  **Explore the Roadmap**: We use Chisel to manage Chisel. Run `chisel issues` in the root of this repository to see what we're working on.
2.  **Conventional Commits**: We use [Conventional Commits](https://www.conventionalcommits.org/) (e.g., `feat:`, `fix:`) to automate our changelogs and releases.
3.  **Local Setup**: See our [Development Setup Guide](./.chisel/docs/community/development-setup.md) for instructions on building and testing the project.
4.  **Submission**: Fork the repository, create a branch, and open a Pull Request.

## Detailed Guidelines

For a full breakdown of our workflow and coding standards, please refer to our [Full Contributing Guide](./.chisel/docs/community/contributing.md).

## Feedback

Since Chisel is local-first, we rely on GitHub Issues for feedback and bug reports. Please feel free to open an issue if you encounter any problems or have ideas for improvements.
