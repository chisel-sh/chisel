Chisel is a text-first toolkit for shaping information. Everything you see here is stored as plain Markdown files in your project.

### Quick Start
- Use **Docs** to manage your project's knowledge base.
- Use **Specs** to track features and decisions through their lifecycle.

### Navigation
- `Tab`: Switch between Category, Document, and Preview panes.
- `j`/`k`: Move selection up and down.
- `q`: Exit the TUI and return to your shell.
